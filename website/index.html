开始转换前

安装 FFmpeg

MP4Flow 使用 FFmpeg 与 ffprobe 读取和转换视频。通过 Homebrew 安装时，两者会一并安装。

  1. 打开「终端」应用。
  2. 输入以下命令： brew install ffmpeg
  3. 安装完成后，重新打开 MP4Flow。

还没有 Homebrew？请先访问 brew.sh 安装。
